The canonical button family. Used in: SetBaselineModal (submit/cancel), DeltaView ("Set Baseline", delete confirmation), the unconfigured-profile banner ("Open Config"), and this page's theme toggle. Primary = one main action per surface; outline for secondary; danger reserved for deletion.

Segmented controls — seg-control / view-mode-btn

seg-control/seg-btn (with built-in dash/check glyphs): the activity-kind filter in DeltaView. view-mode-btn: the Browse ⁄ Compare switch in the commit selector (App.tsx). Choice chips — config-choice

The Config page's service-profile form (ConfigView). Shape encodes semantics: pill + ring-and-dot = radio (pick one); squared + tick box = checkbox (pick any). Disabled state appears when the exclusive "None" is selected in a multi-select.

Severity input — radio where spacious, select where compact

Two deliberate forms for the same field. Severity radio (pill chips, severity-coloured, pick-one): the default wherever there is room — FindingCard edit forms and the quick-add modal. Severity select: the compact fallback, kept only in the Browse side-panel draft where a five-chip row will not fit. Do not introduce new severity dropdowns in spacious layouts.
